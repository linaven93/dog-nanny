# Hundepasser App

This is a simple dog sitter app where users can browse profiles of people who can take care of dogs.

## Features
- Generates 10 random cards on load
- Uses RandomUser API and Dog API
- Delete button replaces cards
- Chat functionality with localStorage
- Filter by dog breed
- Dog speech bubble on click

## Technologies
- HTML
- CSS
- JavaScript
- APIs


## AI usage
ChatGPT was used only for understanding the task and small improvements.
